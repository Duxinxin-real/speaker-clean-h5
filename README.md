# Speaker Clean H5

Mobile audio tools and speaker sound-test demo. Static HTML, CSS and JavaScript hosted on GitHub Pages.

Includes trimming, WAV/M4A/MP3/FLAC export, local file management and share/download controls. Audio imports use generated demo audio. Data is stored locally in each browser, not uploaded to a server.

Open `index.html` through a static HTTP server. Third-party licenses, notices and source packages are in `assets/vendor/`; icon attribution is in `assets/icons/`.
